## Contexte

Valeurs du même tableau pour les sous-origines (contrôlées sur le fichier) : Maghreb 12,9
(Algérie 14,2 ; Maroc, Tunisie 11,9) ; autres pays d'Afrique 14,7 (dont Afrique sahélienne
15,1 ; Afrique guinéenne ou centrale 12,8) ; Turquie, Moyen-Orient 13,2 (dont Turquie 13,0) ;
autres pays d'Asie 9,9 (dont Asie du Sud-Est 6,7) ; Europe du Sud 7,9 (Portugal 5,4 ;
Espagne, Italie 11,7) ; autres pays de l'Union européenne à 27 8,3 ; autres pays d'Europe
16,0. Les sous-origines en italique dans le fichier (« dont ») portent probablement sur de
petits effectifs : prudence dans leur usage.

Pour une ventilation UE / hors UE, seule la source Eurostat (par pays de naissance, et non
par statut d'immigré) est disponible dans le corpus : voir
immigration-chomage-nes-hors-ue-eurostat-2025.
